# 藥液班別用量計算（ChemShiftCalc）

專為工廠藥液每日用量換算早／中／夜三班與比重（Specific Gravity）換算打造的 Android 計算工具 App（v1.1）。

## ✨ 主要功能
- **24 小時日總量即時分班換算**：
  - 內建 5 種常用藥液：`硫酸`、`液鹼`、`氯化鐵`、`亞鐵`、`酸助劑`（可自由新增或移除藥液項目）。
  - 輸入日總量即時算出 **時均用量**（`日總量 ÷ 24`）與三班用量：
    - ☀️ **早班**：`時均 × 8.5 小時`
    - 🌇 **中班**：`時均 × 8.0 小時`
    - 🌙 **夜班**：`時均 × 7.5 小時`
- **藥水比重（SG）設定與 `L ↔ kg` 雙向換算**：
  - 每種藥液皆可點擊卡片上的 **`⚖️ 比重`** 標籤隨時修改比重並自動儲存（預設：`硫酸 1.84`、`液鹼 1.48`、`氯化鐵 1.40`、`亞鐵 1.25`、`酸助劑 1.15`）。
  - 頂部一鍵切換輸入單位：**公升 (L) → × 比重換算公斤 (kg)** 或 **公斤 (kg) → ÷ 比重換算公升 (L)**，日總量與早／中／夜三班同步顯示雙單位結果。
- **彈性設定**：
  - 可自訂早／中／夜班時數、小數位數（0～3 位），並支援一鍵恢復預設值。
- **一鍵複製、分享與歷史紀錄**：
  - 底部固定操作列支援 **複製排版報表（直接貼到 LINE）**、**系統分享**、**存檔至本機歷史紀錄** 與 **清空數值**（二次確認防誤觸）。

## 🛠️ 技術棧與建置環境
- **語言**：Java 17
- **建置工具**：Gradle 9.6.0 / Android Gradle Plugin 9.4.1
- **SDK**：`compileSdk 34` / `targetSdk 34` / `minSdk 24`

```bash
./gradlew assembleDebug
```
